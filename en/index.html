Learn networks by building networks

SimLab Redes is a simulator built for class: students build topologies, configure devices and watch packets travel layer by layer, without installing anything.

Open simulator View the code

Runs in the browser: it also works from a folder or a USB stick, with no server.

What you get

Everything a networking unit needs, with no licences or accounts.

  • Topologies in the browser

    WiFi and L3 routers, switches, PCs, laptops, web and DNS servers, and VPN. Cables are drawn and cut with the mouse.

  • Simulated real traffic

    ARP, ICMP, DHCP, DNS, HTTP and VPN tunnels with packet animation and the detail of every OSI layer.

  • Tables and consoles

    ARP, MAC, DNS and routing tables that update themselves, plus a per-device console to practise commands.

  • Ready for the classroom

    Activities with faults to solve, work hand-in with the student name, and grading for the teacher.

For teachers

The simulator already ships material you can teach with tomorrow.

Activities with faults

Scenarios with a configuration mistake so the student has to diagnose and fix it.

Submit and grade

Students save their network with their name and you open it from “Grade submissions”.

Project in class

Fullscreen mode with large text and high contrast for the projector.

A 45-minute lesson

  1. Open an example or an activity and project it while you explain the topology.
  2. Students rebuild it on their machine and test with ping until it answers.
  3. Everyone saves the network with their name and you open it in “Grade submissions”.

Four exercises to start with

  • Change a PC network so it can ping the other side of the router.
  • Repair a DHCP server that hands out no addresses and check it with ipconfig.
  • Split two groups of devices into VLANs and verify they cannot see each other.
  • Publish a web server behind the router and reach it from the Internet.

Get started in a minute

No sign-up, no install and no dependency on the classroom connection.

  1. 1

    Open the simulator

    It opens in the browser and that is it: no accounts, no downloads.

  2. 2

    Load an example

    The File menu has example networks so you can see the tool in action.

  3. 3

    Save your work

    Save as .json, export to PNG, JPG and PDF, or download an offline copy.
