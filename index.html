    Encontramos tu trabajo anterior

    El simulador guarda tu red automáticamente en este navegador. Para entregarla o compartirla, usá Archivo → Guardar red.

    ¿Cómo te llamás?

    Tu nombre se guarda dentro de las redes y actividades que guardes, así tu profe sabe de quién es cada entrega.

    Crear actividad con esta red

    Armá la red, rompé algo a propósito (una IP, un cable, una ruta…) y definí qué tiene que lograr el alumno. Se guarda como un archivo que el alumno abre con «Abrir red».

    Objetivos: ¿quiénes tienen que poder comunicarse?

    Corregir entregas

    Elegí uno o varios archivos que guardaron tus alumnos. El simulador vuelve a verificar cada red y te muestra quién la resolvió. Con «Ver» abrís la red del alumno para revisarla.

    Actividades: ¡arreglá la red!

    Cada actividad carga una red con una falla escondida. Encontrala, arreglala y verificá.
